# SCIFI: Science Finder

Utility that finds and downloads full pdfs for the selected IDs. Handles DOI, PMID, PMCID and converts between them as needed.

Browse the [documentation](./docs/index.html)

## Sources
- PubMed Open Access
- Unpaywall
- Sci-Hub
